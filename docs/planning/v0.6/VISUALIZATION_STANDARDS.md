# Visualization standards

> v0.1 | 2026-11-24 | Phase 0 review candidate. No implementation authorization.

Visuals are primary, not decorative. Each experiment must answer a clear question; users change meaningful parameters and see consequences immediately or via explicit run controls. Provide reset, labeled axes/units, legends, parameter definitions, accessible keyboard controls and reduced-motion alternatives. Avoid color-only encoding and misleading scaling. Label probability mass versus density. Use fixed or clearly indicated changing axes. Show true algorithm outputs or clearly labeled conceptual illustrations.

Preferred families: PMF/PDF/CDF and sampling; graphical dependencies and inference; latent projections; Bayesian prior/likelihood/posterior; temporal paths; bandwidth/density estimation; class probability and calibration; generator training/sampling; stochastic trajectories. Offer progressive disclosure for beginner and advanced views. Support light/dark modes and mobile layouts. Do not claim illustrative plots are fitted model results.
