## Gaussian science contract
Univariate normal: PDF exp(-0.5*((x-mu)/sigma)^2)/(sigma*sqrt(2*pi)); E[X]=mu, Var[X]=sigma^2. Finite mu, finite sigma>0; controls mu [-3,3], sigma [0.5,2.5], step 0.1, defaults 0,1. Fixed display x [-12,12], axes and units labeled, no clipping at parameter extremes; label finite range and tails. Plot density not probability; explain area and 68.27/95.45/99.73 percent intervals if shown. Pure computation independent of React; parameter snapshot drives chart, equations, mean/variance and Python export; reset returns default. No fake samples. Optional CDF/sampling/fitting explanations may be included as lesson content, but no extra interactive labs required for M001. Include all applicable MODEL_MODULE_SPEC sections or explicitly flag missing sections and keep status partial; never count as accepted full module. Explain estimation (MLE variance uses n), sampling and assumptions accurately, cite reliable references. Provide keyboard controls, accessible numeric/text summary and non-color cues. Python source export uses SciPy, NumPy, Matplotlib with explicit requirements and same plotting domain; downloadable source and copy reflect current parameters. If copy fails provide manual copy. Do not run arbitrary code in browser.
