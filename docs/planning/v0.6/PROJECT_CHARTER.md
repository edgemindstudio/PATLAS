# PATLAS — Project charter

> v0.5 | 2026-11-24 | Phase 0 approved; naming amendment incorporated. No implementation authorization.

## Mission
Make probabilistic modeling visually understandable, mathematically meaningful and computationally reproducible for beginners through researchers. Visual intuition leads; mathematics and runnable code deepen understanding.

## Scope
The entire Founder-supplied tree is mandatory. The JSON baseline preserves all placements; category pages and all named entries must be taught. Additional models may be added through a versioned registry without reducing the baseline. Foundations, comparisons and learning paths support that scope.

## Product commitments
See DECISION_LOG.md (PD-001–008, AD-001–010, VD-001–006). No mandatory accounts or paid access for core learning. Open-source code; MIT for original code and CC BY 4.0 for original educational content confirmed in AD-007; third-party rights separately verified.

## Roles
Founder/associate approves product direction and operates local tools. ChatGPT leads scientific methodology, architecture, planning and review. OpenCode implements explicitly approved tasks and returns evidence; it cannot change scientific scope or approve its own work.

## Non-goals for initial release
Native mobile apps, unrestricted remote execution, full-scale browser training of every deep model, exhaustive coverage of every future published variant. These do not waive baseline learning modules.

## Success
All baseline placements, modules and category pages pass ACCEPTANCE_CRITERIA.md. No placeholder counts as complete.
