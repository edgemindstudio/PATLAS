# Learning module specification

> v0.1 | 2026-11-24 | Phase 0 review candidate. No implementation authorization.

Each category and canonical entry has a stable ID, title, aliases, kind, parent relationships, prerequisites, related entries, status, version, references and owner/reviewer. Category pages explain shared principles and links; broad umbrella entries may use representative examples explicitly labeled as such.

Required lesson sections: plain-language definition; problem/motivation; visual intuition; structure; symbols and equations; derivation or explanation; interactive experiment; fitting, inference and sampling when applicable; runnable code; applications; assumptions and limitations; related models; knowledge check; references.

For every lab: objective, parameter schema (units, bounds, defaults), deterministic seed/reset when relevant, computation source, chart labels, instructions, expected observations, numerical tests, accessible text alternative and execution environment. Link code to the same computation or verify equivalent implementations. Download/copy source and instructions for dependencies. Non-applicable sections require a reason and reviewer acceptance, not silent omission.

Lifecycle: planned → drafted → implemented → verified → accepted. Blocked is an explicit state with reason. Acceptance needs evidence and lead review.
