# PATLAS — Phase 2 visual product design (confirmed direction; detailed design candidate)
## Experience
See → explore → understand → implement → master. Visual intuition leads; equations and code accessible without requiring expert background. Public, no mandatory account. Light/dark themes. Proposed tagline: Explore. Visualize. Understand. Approved mark concept: probability curve on axes; not final artwork.
## Information architecture
Home: hero with a real miniature probability experiment when implemented, nine branch cards, start learning, research-oriented links. Model Explorer: searchable semantic expandable tree, optional relationship graph, branch breadcrumb and detail panel. Foundations: prerequisite library. Visual Lab: searchable experiments, parameter controls, chart, interpretation, equations and code. Compare: select two or three compatible entries; show shared quantities and caveats, do not equate incompatible densities. Learning Paths: beginner probability, statistical modeling, generative modeling and research paths. Code: searchable source examples, declared environment, copy/download, editable runner only after isolation verification. Global search and theme switch; public repository link when available.
## Lesson layout
Breadcrumb, title, type, status; plain-language question; core lab above long prose; observable behavior and explanation; equations and symbol-to-visual mapping; optional derivation; fitting/inference/sampling where appropriate; runnable source and references; related concepts and knowledge check. Tabs or anchors preserve deep links. Beginner/advanced disclosure does not hide essential assumptions. Category pages teach common mechanisms and list placements; planned content clearly labeled, not counted complete.
## Interaction contract
Parameter edits validated and synchronized with chart, equations and exported source. Reset defaults and seed; explicit resample where appropriate; play/pause/step for animations; no autoplay by default; reduced motion alternatives. State remains local by default, shareable URL for validated small parameter snapshots proposed. Preserve tree context when following canonical lesson. No fake output or invented confidence.
## Graph
Use tree as accessible default; graph is optional complementary visualization, scoped to selected neighborhood with edge labels, zoom/pan/reset and text equivalent. Preserve baseline placements; relationships distinguish membership, variants, prerequisites, mechanisms and relatedness. Search canonical title and aliases; results display branch context and status. Do not equate every family with a model.
## Responsive
Desktop: persistent explorer sidebar, main learning area, optional details pane; tablet: collapsible sidebar; phone: drawer, single column, no horizontal page overflow, graph has accessible list. Charts and code may use contained scrolling where needed. Focus management, keyboard navigation, touch targets, contrast, semantic headings and non-color encodings required.
