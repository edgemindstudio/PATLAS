# OpenCode workflow

> v0.1 | 2026-11-24 | Phase 0 review candidate. No implementation authorization.

For each bounded task, ChatGPT supplies objective, authorized scope, paths, constraints, acceptance tests and stop conditions; Founder executes it. OpenCode inspects repo state before changes, implements only authorized work, runs relevant tests, and returns changed files, diff summary, commands/results, failures, assumptions, commit status and outstanding issues. No secrets, destructive commands, deployment or pushes without authorization. Never claim a test was run when it was not. Stop for scope ambiguity or conflicting scientific instructions; propose options rather than independently resolving them. Lead reviews evidence; Founder approves major decisions. Update ledger and handoff after accepted milestones.
