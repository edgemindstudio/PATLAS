## Eight work packages and contracts
**WP01 — Learning record.** Registry authoritative for IDs/placements. Learning record: schemaVersion, contentVersion, entry(kind,id), title, scientificKind, summary, objectives(id,statement), prerequisites(title, optional entry, explanation), sections(id,title,blocks,objectiveIds,referenceIds), labIds, exampleIds, referenceIds, relatedEntryRefs, ownerId. Structured blocks markdown/equation/lab/code-example/related-entries/references; equation IDs resolve to typed equation records (id,tex,caption). Reference records id/authors/title/year/url or DOI/locator/attribution; claim mapping section/claim/reference/locator. Reviewer in review record. Validate identity/title consistency, uniqueness, all required sections, known refs, block types, explicit justified N/A and reviewer disposition. Retain existing anchors where feasible. No arbitrary executable content. Category/foundation reference types may be represented without implementing their lessons.

**WP02 — Lifecycle.** Stage planned/drafted/implemented/verified/accepted. Separate coverage requirements (missing/partial/satisfied/not-applicable, reason, evidence, reviewer), blockers (id,reason,affected requirements,disposition), review and acceptance records. Partial visible as coverage, blocked explicit. Legacy Gaussian proposed drafted with implemented-component evidence and partial coverage; does not demote M001. Planned records need no content version. Acceptance binds moduleId, contentVersion/digest, implementationCommit, leadReviewId, evidenceManifestId, decisionId, acceptedBy/At and exceptions. No self-promotion by content JSON or tests. New content revision does not inherit old acceptance; history retained. Counts distinguish routes, authored, implemented, verified, accepted.

**WP03 — Registration/rendering.** Explicit trusted moduleId→lessonRef manifest, server validation and public serializable DTO (identity,title,summary,placements,objectives,sections,labs,relatedEntries,references,status). Route resolves registry first, 404 unknown; known unregistered planned page; malformed registered record fails validation, not disguised as planned. Common renderer with header, sections, equations, registered labs, examples, refs and coverage. No path derived from user URL, dynamic code or server-only dependencies in client. Preserve all canonical routes, placement labels/order; branch context if supplied must resolve. Bernoulli added without second general route branch/renderer. HMM test fixture can prove multi-placement context without new lesson.

**WP04 — Lab/controller.** Descriptor id,moduleId,title,objectiveIds,instructions,expectedObservations,parameters,views/defaultViewId, trusted computeRef/rendererRef/exportRef,seedPolicy,executionTier,verificationProfileId. Numeric control id,label,symbol,unit,min,max,step,default,decimals,description. Model math validator separate from UI grid. Draft/error state per field, one authoritative applied state; update atomically, invalid draft never changes result/export, reset restores defaults. Grid canonicalize accepted near-grid inputs deterministically, not arbitrary rounding; preserve Gaussian tolerance and bounds; explicit policy for boundaries, finite parsing and negative zero. Snapshot schemaVersion,moduleId,labId,computationVersion,parameters,computationConfig,optional seed; separate active view. Immutable semantic snapshot drives plot, equation, statistics, summary and export. Gaussian lab id and defaults retained; Bernoulli one lab with two views. Deterministic labs seed N/A. RI-001 proposed resolution here.

**WP05 — Science/results.** Adapter validateParameters,validateConfig,compute(snapshot),describe(snapshot,result), delegates to pure model functions. Typed union density(points x,y,units), probability-mass(outcomes x,probability,label), cumulative-step(right continuity, initial/final probability, ordered jumps x,before,at). Envelope series, scalar statistics(id,label,value,unit,semantic), disclosures(code,severity,explanation). View axis labels/units/domain/scale policy; correct CDF endpoint markers, no smooth mass interpolation; finite/nonnegative density (may exceed 1), masses [0,1] normalized, cumulative nondecreasing [0,1]. Gaussian display window not normalization proof. Renderers common axes/layout but model-specific overlays and meaningful accessible descriptions. Fail explicitly on invalid results. No universal engine.

**WP06 — Code.** Artifact id,moduleId,kind(snapshot-reproduction/educational-example),language,title,objectives,filename,environmentId,executionTier local-download, exactly one trusted sourceRef or generatorRef, instructions,expectedOutputs,seedPolicy,refs. Environment runtime version, pinned dependencies, platform/install/run notes; distinguish test/runtime deps. Seed policy N/A with reason or fixed seed/generator/reproducibility scope. Preserve Gaussian snapshot export; Bernoulli reproduces applied p and both views. Companion sampling/fitting/inference examples model-specific, local only. Shared preview/copy/manual fallback/download, execute actual downloaded files during future verification. No arbitrary Python browser/server execution. No unapproved dependency changes.

**WP07 — Verification.** Reference protocol caseId,moduleId,operation,parameters, operation-specific config and points(id,x); response echoes identity, coordinates and value or scalar. Validate exact case/point sets, no duplicate/missing/extra, matching params/config/operation, finite and semantic validity before comparisons. Model-specific profiles operation/ref/fixture/tolerance; exact categorical/int tests. Preserve Gaussian thresholds and fixtures; Bernoulli 120 planned comparisons, abs 1e-12; independent analytic checks for companion examples. RI-003 explicit point identity. RI-002 unique external/ignored run output, no overwrite evidence/correction. Manifest runId/schema, source commit and candidate tree/inventory digest if dirty, content versions, times, runtime/dependency digests, commands/exits, artifacts(path/hash/bytes), passed/failed/blocked and limitations. Preserve failures; publish only authorized screened evidence.

**WP08 — Integration.** Both canonical routes through shared renderer/controller and independent science; preserve baseline and search; planned/unknown route behavior; retain synthetic registry extension regression and add isolated educational fixture. Verify actual exports, production build/start, interactions and both themes, 320/768/1280, keyboard/focus/error labels, numeric plot alternative, contrast, reduced motion, real native 200% zoom and manual screen-reader checks as applicable. No automatic reuse of M001 exceptions; no WCAG certification claim.

## Dependencies and invariants
Routes compose server services; server validates content and registry and builds DTO; client features import shared serializable contracts, UI and pure science; science imports no React/Next/DOM or server I/O; UI does not govern identities or acceptance; independent Python references do not import tested implementation; tests never runtime authority. Preserve existing directory/file names where practical; exact file inventory deferred. Invariants INV-01–17: original placements unchanged; stable URLs; identity separate from status; no executable authored content; no server imports in browser; pure science; invalid drafts never applied; single validated snapshot; distinct density/mass/CDF semantics; model-specific references/tolerances; recorded stochastic reproducibility; immutable historical evidence; version-bound acceptance; honest partial/planned status; justified N/A; no new execution/security boundary without authorization; historical M001 acceptance intact.
